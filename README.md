# e-plantShopping - Paradise Nursery

Welcome to **Paradise Nursery**, your ultimate destination for high-quality houseplants. This React-based web application allows users to explore a diverse collection of indoor plants categorized by their care needs, manage a dynamic shopping cart, and seamlessly track their total expenses.

## Repository Name
`e-plantShopping`

## Key Features
* **Immersive Landing Page:** Features a welcoming interface with an entry point to the store.
* **Categorized Product Listing:** Showcases 18 unique plants split across 3 distinct categories.
* **Dynamic State Management:** Powered by Redux Toolkit to track cart additions, item quantities, and real-time badges.
* **Interactive Shopping Cart:** Allows quantity adjustments, instant deletion, cost breakdowns per item, and checkout simulation.

## Tech Stack
* **Frontend:** React (Vite)
* **State Management:** Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
* **Styling:** Pure CSS3
* **Icons:** Lucide React
